# RCON Warfare — правила проекта

Устройство и инварианты подробно — в [`ARCHITECTURE.md`](ARCHITECTURE.md).
Здесь — короткий свод правил, домен и грабли.

## Что нельзя
- Ядро (rwf/*.py кроме ui/) не импортирует dearpygui.
- UI не делает сеть. Только CoreFacade.send().
- Команды на сервер — только через CommandQueue.
- Модель убирает только свои блоки (BlockModel._placed).
- Углы — только из rwf.geometry (одна математика на весь проект).
- Модель ставить через round(), не int() — на отрицательных int(-3.7)=-3.
- **Проекция не ходит на диск каждый кадр.** Если данные нужны в кадре —
  кэшировать у владельца данных (регресс FPS-03: 9 чтений JSON на кадр =
  2.4 fps).
- **Проверка «изменилось ли» — ДО дорогой работы.** Кэш `sig` бесполезен,
  если подпись считается после чтения данных.

## Что обязательно
- Все производные в физике × dt.
- set_target(pitch=-10) — это «держать −10», не «прибавить −10».
- BlockModel.sync идемпотентна — не вызывать без изменения позы.
- Боты используют Route.replace_waypoints при перепланировании,
  не создают новый маршрут (иначе прогресс сбрасывается).
- Регрессионные метки в комментариях (UNIT-11, ROUTE-04, DPG-11) — не удалять.
  Это исполняемая документация вместе с тестами.

## Домен
- yaw 0 = юг (+Z), 90 = запад (−X). Это Minecraft, не математика.
- pitch < 0 = нос вверх, pitch > 0 = нос вниз.
- Согласованный вираж: n = 1/cos(φ), ω = g·tan(φ)/V.
- Сваливание — реально, снижение скорости < stall_speed.
- Армейские ТТХ реальные (Су-25: max_g=4.5, stall=9 м/с; МиГ-29: max_g=9).

## Версии
- Цель — 1.20.1 vanilla (Paper/Spigot ок).
- NBT: legacy до 1.21.2, modern с 1.21.2. Только через NbtDialect.

## Имя проекта и совместимость
- Официальное имя — **RCON Warfare**, сокращение **RWF**; `Bomber` — только
  историческое (CHANGELOG, старые версии).
- Настройки: файл `rwf.json`; переменные окружения `RWF_*`
  (`RWF_HOST/PORT/PASSWORD/MOCK/TICK/CONFIG`). Прежние `BOMBER_*` принимаются
  как устаревший псевдоним — не удалять без решения заказчика.
- В игре сообщения идут с префиксом `[RWF] ` (`mc.tellraw`, `gamefx.GameFX`).

## Dear PyGui 2.3.1 — что уже оплачено багами
- `get_item_rect_min/max` **у окон не работают никогда** (`KeyError('rect_min')`),
  у drawlist — работают. Прямоугольник окна: `get_item_pos` + `get_item_rect_size`.
- `add_tooltip` на контейнерах — abort в нативном слое, `try/except` не берёт
  (`build._TIP_UNSAFE`).
- `dpg.tooltip(...)` как контекст-менеджер роняет стек контейнеров.
- Цвета темы — только через `add_theme_component`, не `add_theme_color(parent=theme)`.
- Один DPG-контекст на процесс; проверки интерфейса — внутри `on_frame`.

## Диагностика
- Профиль фаз кадра: `RWF_PROFILE=1 python main.py gui` (раз в 30 кадров).
- Полный прогон: `python main.py --selftest` или `python -m pytest tests/ -q`.
- Переснять golden-эталоны силуэтов: `RWF_UPDATE_GOLDEN=1 pytest tests/test_golden.py`.
- Отключить сквозной UI-тест там, где нет рабочего стола: `RWF_NO_UI=1`.
